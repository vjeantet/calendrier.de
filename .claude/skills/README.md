# Skills de Matt Pocock

Copie des skills du plugin `mattpocock-skills` (v1.3.2), depuis https://github.com/mattpocock/skills au commit `4ae2317ddb22b046e26455e4f9c9b3aaaf62212d`. Liste reprise de `.claude-plugin/plugin.json` : les dossiers `in-progress/` et `misc/` du dépôt n'en font pas partie.

Copie figée : pour mettre à jour, recopier les dossiers depuis une version plus récente du dépôt.

Avant d'utiliser `/wayfinder`, `/to-tickets` ou `/triage`, lancer une fois `/setup-matt-pocock-skills` pour choisir le gestionnaire de tickets.
